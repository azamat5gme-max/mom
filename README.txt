Сайт для мамы

Как открыть:
1. Просто дважды нажми на index.html: сайт откроется в браузере.
2. Чтобы отправить маме ссылкой: зайди на app.netlify.com/drop и перетащи туда эту папку целиком. Сайт получит адрес в интернете.

Нужен интернет, чтобы загрузились красивые шрифты (Google Fonts). Без интернета сайт тоже работает, но шрифты будут обычными.
